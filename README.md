# I figli dell'algoritmo — sito di presentazione

Sito statico di presentazione del libro **I figli dell'algoritmo** di Claudio Biancalana.

## Pubblicazione con GitHub Pages

1. Crea un nuovo repository GitHub, ad esempio `figli-algoritmo-book-site`.
2. Carica il contenuto di questa cartella nella radice del repository.
3. In **Settings → Pages**, seleziona **Deploy from a branch**, quindi il branch `main` e la cartella `/(root)`.
4. Salva: GitHub Pages pubblicherà automaticamente il sito.

Non richiede installazioni, dipendenze o build. Per un'anteprima locale, apri `index.html` nel browser.

## Struttura

- `index.html` — contenuti e struttura
- `styles.css` — identità visiva e responsive design
- `script.js` — menu mobile, animazioni di entrata e indicatore di lettura
- `assets/` — copertina e illustrazioni originali del libro
